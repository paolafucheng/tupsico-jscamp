### Frontend vs Backend
- Frontend: lo que ve el Cliente. Ej: páginas webs, aplicación móvil, nevera, lavadora. Todo con lo que el usuario interactua.
- Backend: o que no se ve, como: Servidor Web, Servidor de Aplicaciones, Base de Datos. Ej: datos, cálculos, temas de negocio.
- FullStack: lo es todo, tanto Frontend como Backend. Se encarga de todo el ciclo del producto (crea el producto, genera todo lo que necesita el backend, frontend para que llegue al cliente).
- API: permite que diferentes aplicaciones de software se comuniquen e intercambie datos entre sí.

### El proyecto: TuPsico
En este Bootcamp el instructor hace una aplicación de búsqueda para encontrar trabajo. Para no hacer un copia y pega, he decidido hacer una página web de búsqueda de psicoólogos, parecida a Psychology Today.
